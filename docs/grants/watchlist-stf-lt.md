# Watchlist — Sovereign Tech Fund and Lithuania programmes

Monitor for Phase 3+ (2027–2028). **Not in the main path for Phase 1.**

## Sovereign Tech Fund (STF)

| Field | Detail |
|-------|--------|
| URL | https://www.sovereign.tech/ |
| Minimum | EUR 50,000 |
| Applicant | Prefer legal entity; individual possible with strong track record |
| Fit | Open manufacturing infrastructure, NativeCAM as EU digital sovereignty tool |
| When | After Phase 2 deliverables public (mid–2027 earliest) |
| Pitch angle | Same NativeCAM project → LinuxCNC or Siemens; GPL commons for EU workshops |

### STF readiness checklist

- [ ] 2+ successful NLnet phases with public GitHub releases
- [ ] Security audit completed (Phase 3)
- [ ] Consider UAB registration for contracting
- [ ] Community metrics: GitHub stars, forum activity, `.deb` downloads
- [ ] Demo video + FOSDEM or LinuxCNC conference talk

### Monitor

- STF application windows: check sovereign.tech/news quarterly
- Subscribe: STF newsletter

## Lithuania — CPVA / InnoLT / ES investicijos

| Programme | Min | Requirement | Fit |
|-----------|-----|-------------|-----|
| CPVA startup support | EUR 40,000+ | UAB, often Vilnius | Robotics/DI/CNC product |
| InnoLT | varies | UAB, innovation | Manufacturing software |
| esinvesticijos.lt | varies | EU structural funds | Check manufacturing/digital |

### LT readiness checklist

- [ ] Register UAB (CNC Proton or new entity)
- [ ] Business plan aligned with NativeCAM product roadmap
- [ ] No double-funding: same WP cannot be in NLnet and LT grant simultaneously
- [ ] Monitor https://esinvesticijos.lt for open calls

### Monitor

- CPVA: https://cpva.lt — quarterly
- Enterprise Lithuania: innovation funding announcements
- Cascade Funding Hub: https://cascade-funding.eu — search manufacturing, robotics
